# PREDOC.org Scraping Project README
*Shaylee Louth, Last Updated 9/28/2025*

## Project Introduction
The initial purpose of this project was to apply the web scraping skills I have recently learned to a real-world, personally-useful task. The end goal of this project is to create a program that will assist in job application management by regularly scraping new listings from [PREDOC.org](https://www.predoc.org) and incorporate them into an existing, organized dataset without overwriting previous scraped entries or manual data entries.

## Work-In-Progress
Please note that this project is still in development. While the basic scraping code can successfully pull information from the website, the data cleaning is currently in progress.

## How to Run
This project is currently under development, however, the raw, most-recent job posting data from PREDOC.org can be scraped into a CSV file by simply running the file:

* predoc_scraper.py

Which will return the file:

* predoc_raw_data.csv
