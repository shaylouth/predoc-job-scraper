# PREDOC.org Scraping Project README
*Shaylee Louth, Last Updated 8/8/2025*

## Project Introduction
The initial purpose of this project was to apply the web scraping skills I have recently learned to a real-world, personally-useful task. The end goal of this project is to create a program that will assist in job application management by regularly scraping new listings from [PREDOC.org](https://www.predoc.org) and incorporate them into an existing, organized dataset without overwriting previous scraped entries or manual data entries.

## Work-In-Progress
Please note that this project is still in development. While the basic scraping code can successfully pull information from the website, there is significant work to do in terms of cleaing up and organizing the output.

## How to Run
At this early project stage, the output is very messy and not yet organized. However, the raw PREDOC.org data on the most recent job postings can be scraped into a CSV file by simply running the file:

* PREDOC.org_scraper.py

Which will return the file:
* predoc_job_data.csv
